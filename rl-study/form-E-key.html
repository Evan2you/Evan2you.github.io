II. Short-answer questions

25 points

B1. Reading the notation [5 points]

Reward is immediate; return accumulates future rewards. V averages over the policy’s first action; Q fixes it. max returns a value, argmax an optimizer. k indexes sweeps, t indexes transitions. α controls update size; ε controls exploration.

Detailed Chinese explanation →

B2. MC and TD with repeated visits [5 points]

Visit conventions determine which returns are used; step-size conventions determine how those returns are averaged. Online TD reads the current table after earlier updates, so transition order matters.

Detailed Chinese explanation →

B3. Choose the correct DQN improvement [5 points]

Replay: reuse and decorrelation. Target network: slower targets. Double: separate selection and evaluation. PER: nonuniform experience sampling with correction. Dueling: value/advantage decomposition.

Detailed Chinese explanation →

B4. A small REINFORCE calculation [5 points]

π(a₁)=0.5, score gradient=0.5, θnew=0.1. The probability of a₁ increases to about 0.525. The action-independent baseline centers the return without changing the expected gradient.

Detailed Chinese explanation →

B5. Learning, planning and model errors [5 points]

Model-free updates use real experience directly; planning uses a model. Dyna learns from real transitions, updates its model, and performs additional model-generated updates. Model bias can be amplified by excessive planning.
