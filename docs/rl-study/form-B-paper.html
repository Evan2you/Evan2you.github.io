III. Calculation — MDP

25 points

C1. A two-state Markov reward process [8 points]

There are nonterminal states A, B and terminal state T. γ=0.5. From A, the immediate reward is always 2; the next state is A or B with probability 0.5 each. From B, the reward is always -1; the next state is A or T with probability 0.5 each. T is absorbing with zero reward.

(a) Write the transition matrix in the order (A,B,T) and the expected reward vector. [2]

(b) For the observed episode A → B → T, compute G₀ and G₁. [2]

(c) Write and solve the Bellman equations for v(A),v(B). [2]

(d) From V₀=(0,0), calculate the synchronous vectors V₁ and V₂. [2]

C2. Policy evaluation and one improvement [8 points]

γ=0.5. In S, action stay gives reward 1 and returns to S; move gives reward 0 and goes to U. In U, cash gives reward 4 and terminates; reset gives reward 0 and goes to S. Policy π selects each available action with probability 0.5.

(a) Write the Bellman expectation equations under π. [2]

(b) Solve for vπ(S) and vπ(U). [2]

(c) Compute qπ for all four state-action pairs, and give a greedy improved policy π′. [2]

(d) Evaluate π′. Is its action at S uniquely greedy with respect to vπ′? Explain. [2]

C3. A 2 × 3 grid [9 points]

The grid has two rows and three columns. (1,1) and (2,3) are terminal. Four actions (up, down, left, right) are equiprobable. A move outside the grid leaves the state unchanged. Every move FROM a nonterminal state gives reward -1, including a move entering a terminal. γ=1; terminal values are fixed at zero.

(a) Write the synchronous random-policy update equation. [1]

(b) Starting from V₀=0, give the whole V₁ grid. [2]

(c) Give the whole V₂ grid. [2]

(d) Calculate V₃(1,2) and V₃(2,1). [2]

(e) Using V₂ for successor values, compute all four one-step action values at (1,2) and identify every greedy action. [2]

IV. Calculation — Learning algorithms

20 points

D1. Repeated states: MC and online TD [10 points]

An episode is A --2→ B --(-1)→ A --4→ T. γ=0.5. For constant-step-size algorithms initialize V(A)=0, V(B)=2 and use α=0.5. Run each named algorithm independently from these initial values.

(a) Compute G₀,G₁,G₂. [2]

(b) Apply first-visit MC with the stated constant α once per visited state. [2]

(c) Using ONLY this episode and fresh zero counts, compute every-visit sample-mean MC estimates. [2]

(d) Apply online TD(0) in chronological order; show the value after each update. [3]

(e) Explain why the TD update at the second transition uses a value that has already changed. [1]

D2. Four targets from one transition [10 points]

A nonterminal transition has current Q(S,A)=1, reward r=-1, γ=0.8 and learning rate α=0.25. Online next-state values for (a₁,a₂,a₃) are (5,2,0). The actual next action is a₂. The behaviour is ε-greedy with ε=0.3. Target-network next-state values are (1,4,3). Compute each algorithm independently.

(a) Give the behaviour probabilities of a₁,a₂,a₃. [2]

(b) Give the SARSA target and updated Q(S,A). [2]

(c) Give the Q-learning target and updated Q(S,A). [2]

(d) Give the standard DQN and Double DQN targets. Show which next action each selects. [3]

(e) If the transition instead terminates, give its target and tabular update. [1]
