Instructions and conventions

Answer all 21 numbered questions. Each single-choice question has exactly one correct answer. There is no penalty for an incorrect answer. Show your working in Sections III-V; method marks are available.

Use the reward-on-transition convention: Rt+1 is received after action At. All terminal states have value zero and no future rewards. A reward on entry into a terminal state is still counted.

For every ε-greedy question, exploration is uniform over ALL available actions, including greedy actions. If several actions are tied for the maximum, split the exploitation probability equally among them.

Unless stated otherwise, use synchronous DP updates: every value in sweep k+1 is computed from the complete vector in sweep k. Different questions and independently specified algorithms start from their own stated initial values.

Give exact fractions or at least four decimal places when appropriate. Write short answers in English. The separate answer booklet provides Chinese explanations and marking guidance.
