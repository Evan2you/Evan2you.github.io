II. Short-answer questions

25 points

B1. Prediction versus control [5 points]

Prediction evaluates a fixed policy; control searches for an optimal policy. Policy iteration alternates evaluation and greedy improvement. max returns a value, whereas argmax returns an action attaining that value.

Detailed Chinese explanation →

B2. GLIE is a property [5 points]

GLIE requires infinite exploration and a policy that becomes greedy in the limit. It is a property of a policy sequence. Fixed positive ε generally violates the second condition; εₜ → 0 alone does not ensure the first.

Detailed Chinese explanation →

B3. DQN and Double DQN [5 points]

DQN selects and evaluates with the target network. Double DQN selects with the online network and evaluates with the target network, reducing the coupling that contributes to maximization bias.

Detailed Chinese explanation →

B4. Prioritized replay [5 points]

PER samples experiences according to priorities such as absolute TD errors. Positive offsets retain sampling support; importance weights compensate for nonuniform sampling, with β controlling the correction strength.

Detailed Chinese explanation →

B5. REINFORCE and Actor–critic [5 points]

REINFORCE weights the score-function gradient by Gₜ−b(Sₜ). The actor learns the policy; the critic estimates values. A one-step TD error can serve as an approximate advantage signal.
