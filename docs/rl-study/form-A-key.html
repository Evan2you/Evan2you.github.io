Conventions used throughout

Rt+1 is received on the transition after action At. A terminal state has value zero, but the reward received on entering it still counts. Exploration in ε-greedy is uniform over all available actions, including greedy actions.

Synchronous DP uses the previous complete value vector. Online TD immediately retains each update for subsequent transitions. Independent methods restart from the initial estimates specified in the question.

How to use this booklet

Try the English paper under the 120-minute limit before checking the answers. The short-answer solutions are model responses: equivalent explanations and mathematically equivalent formulas are acceptable. Extra explanatory notes help with revision and need not all be reproduced in an exam.

For calculations, show the target or Bellman equation, substitute the numbers, and give the result. Where a later result inherits an earlier arithmetic error, award valid method marks rather than repeatedly penalizing the same error.

Section I - solutions

A1-A5: Foundations and evaluation

A1. B - The Markov property [2 points]

Given the current state and action, the conditional distribution of the next state and reward does not require earlier history. Transitions may still be random. A state can summarize relevant history without storing every past observation. Rewards may depend on the action.

Reference: RL-3, states and the Markov property; RL-4, the MDP definition.

A2. C - Discounted return [2 points]

The first reward is not discounted. The third reward is multiplied by γ². Option A gives the undiscounted sum, 5.

Reference: RL-4, pp. 18-25.

A3. A - Average over the policy [2 points]

Under a fixed policy, actions are selected with probabilities π(a|s), so the state value is the probability-weighted average of their action values. A maximum describes a greedy choice and cannot replace this average for an arbitrary policy. An unweighted sum also omits the required probabilities.

Reference: RL-4, pp. 42 and 48-52.

A4. D - Use the previous complete sweep [2 points]

In synchronous policy evaluation, every entry of Vk+1 is computed using Vk. Using values already updated during the same sweep would be an in-place update, contrary to the convention in this question.

Here k counts evaluation sweeps. It is not an episode number or an environment time step; an index must be interpreted in its algorithmic context.

Reference: RL-5, pp. 8-14.

A5. B - Exploration can also select the greedy action [2 points]

Each other action has probability 0.05, and the four probabilities sum to 1. The value 0.80 counts only the exploitation branch; 0.20 is the probability of entering the random-exploration branch.

Reference: RL-7, pp. 16-18. Award 2 points for the correct option in each question.

Section I - solutions

A6-A10: Control and deep RL

A6. C - Actual next action versus a maximum [2 points]

SARSA uses the target r+γQ(s',a'), where a' is the next action actually selected by the behavior policy. Q-learning uses r+γ max Q(s',a') in its target while the behavior policy may continue exploring. Neither method requires a known transition model.

Reference: RL-7, pp. 34-36 and 55-61.

A7. A - Parameter sharing and generalization [2 points]

A parameterized value function avoids storing an independent entry for every state and can generalize from visited states to unseen states. This is useful in large or continuous state spaces. Approximation may introduce error and does not guarantee convergence of every learning algorithm.

Reference: RL-8, pp. 9-11.

A8. D - Subtract the mean raw advantage [2 points]

Option A omits mean subtraction. Option B subtracts the maximum advantage, a different aggregation rule from the mean-centered rule specified. Option C omits the value stream.

Reference: RL-10a, pp. 32-39.

A9. B - Avoid predictable behavior [2 points]

In rock-paper-scissors, an adaptive opponent can exploit a predictable deterministic action. Uniform random play avoids that particular exploitability. This does not imply that stochastic policies are strictly better in every fully observed finite discounted MDP; under standard assumptions, such an MDP has a deterministic stationary optimal policy.

Reference: RL-11, pp. 12-19.

A10. C - Generate simulated experience [2 points]

Dyna combines real interaction, model learning, and planning. A learned model predicts rewards and successor states, allowing extra value updates from simulated transitions between real interactions. The model must be learned from data, and model errors can affect the resulting policy.

Reference: RL-12, integrating learning and planning / Dyna. This is the supplementary topic outside the photographed list. Award 2 points for each correct option.

Bootstrapping means using another current value estimate in the update target. DP and TD use estimated successor values. Standard complete-episode MC uses the observed return instead.

For a fixed policy, the complete return Gt is an unbiased sample of vπ(St), but it usually has relatively high variance because it depends on many random future events. A practical TD target r+γV(s') uses an approximate value estimate, so it may be biased, but its variance is often lower.

If V equals the true vπ, the one-step TD target is also unbiased conditional on the current state. The usual variance comparison is not a universal ordering for every possible example. These statements concern targets, not the unbiasedness of every finite-step estimator.

Marking: 1 point for each fully correct table row (3 total); 1 for the MC bias/variance explanation; 1 for the TD explanation.

B2. GLIE and ε-greedy [5 points]

GLIE means Greedy in the Limit with Infinite Exploration. It requires both of the following:

1. Infinite exploration: every relevant state-action pair is visited infinitely often in an indefinitely continued learning process.

2. Greediness in the limit: the policy approaches a greedy policy with respect to its current action-value estimates; the total probability of nongreedy actions approaches zero.

With fixed ε=0.1, nongreedy actions retain positive probability whenever such actions exist, so the policy does not generally become greedy in the limit. Conversely, εk→0 alone does not guarantee sufficient exploration: decay may be too fast, or some states may remain insufficiently visited.

MC specifies how values are updated using complete returns. ε-greedy specifies how actions are chosen. GLIE specifies asymptotic exploration and greediness requirements for a sequence of policies. Using ε-greedy within MC control does not automatically establish GLIE.

Marking: 1 point for each GLIE condition; 1 for fixed ε; 1 for why decay alone is insufficient; 1 for distinguishing MC, ε-greedy, and GLIE.

References: RL-6, pp. 21-28 and 40-43; RL-7, pp. 16-24. GLIE is adjacent review material to ε-greedy.

Purpose of the baseline [1 point]

A suitable baseline reduces the variance of the gradient estimate and can make learning more stable. A common choice is b(s)=V(s). Then Gt-V(St) measures how much better or worse this outcome was than the usual value of the state. An arbitrary baseline is not guaranteed to reduce variance.

Actor and critic [1 point]

The actor is the policy πθ and determines how actions are selected. The critic estimates values or advantages and supplies an evaluation signal that guides policy improvement. The critic learns an evaluation; the actor improves the policy using that evaluation.

Six checks before submitting an answer

1. Discount positions: the first reward has coefficient 1, then γ, then γ².

2. Probabilities: computing Q fixes the current action; computing V averages over actions using π. Random state transitions still require weighting by P.

3. Update order: synchronous DP uses the old complete vector; online TD uses estimates already updated earlier in the trajectory.

4. Targets: MC uses G; TD uses r+γV'; SARSA uses the selected next Q; Q-learning uses the maximum next Q.

5. Deep-Q variants: Double separates selection and evaluation; dueling separates value and advantage streams; prioritized replay changes sampling.

6. Limits: ε→0 alone does not establish GLIE; one greedy improvement need not be optimal; a tie under V2 need not persist under v*.
