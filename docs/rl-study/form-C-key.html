II. Short-answer questions

25 points

B1. DP, MC and TD comparison [5 points]

DP uses model-based expected bootstrapped backups. MC uses sampled complete returns without bootstrapping. TD uses sampled bootstrapped targets and can update before termination. MC commonly has higher variance; TD can have bias from its value estimates.

Detailed Chinese explanation →

B2. Policy improvement theorem [5 points]

A greedy action attains at least the policy-weighted average qπ value. Repeated Bellman comparison yields vπ′≥vπ. Stability after exact evaluation implies optimality; an unchanged approximate sweep alone does not.

Detailed Chinese explanation →

B3. Why Q-learning is off-policy [5 points]

Q-learning learns a greedy target policy from data generated by a potentially exploratory behaviour policy. SARSA evaluates the actual behaviour, including exploration risk, while Q-learning bootstraps from a greedy next action.

Detailed Chinese explanation →

B4. Dueling is not Double [5 points]

Dueling separates a shared state-value stream from action advantages and combines them with mean subtraction. Double DQN instead separates action selection from evaluation in the target; the two ideas are compatible.

Detailed Chinese explanation →

B5. Function approximation risks [5 points]

Function approximation compresses a large value table and generalizes through shared features. A linear approximator uses x(s)ᵀw; a semi-gradient update holds the target fixed while differentiating the current prediction. Shared parameters can cause approximation error or interference.
